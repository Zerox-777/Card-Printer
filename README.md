# TCG Card Print Maker 🎴
A web application designed to organize trading card images and export print-ready PDF files.

### Key Features:
* Multiple Card Sizes: Supports both Japanese size (59x86mm) and Standard size (63x88mm).
* Auto-Layout: Automatically arranges 9 cards per A4 sheet for optimal printing.
* Persistent Storage: Saves your decklists locally on the browser using IndexedDB.
* Efficient Management: Support for Direct Copy,Edit,and Printing features from your collection.

### Tech Stack:
* Frontend: HTML5,CSS3,JavaScript (ES6+).
* PDF Engine: jsPDF for high-quality PDF generation.
